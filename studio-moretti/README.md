# Studio Legale Rossi

Concept project: a website for a law firm in Milan: practice areas, about, testimonials, articles and contact. Nine routed pages in five languages (IT, EN, DE, ES, PT), with Schema.org structured data, sitemap and robots for local SEO.

**Live demo:** https://studio-legale-rossi-taupe.vercel.app/ · Part of my portfolio at [npdevelopment.xyz](https://npdevelopment.xyz)

**Stack:** React · Vite · React Router

## Run locally

```bash
npm install
npm run dev     # development server
npm run build   # production build in dist/
```
