# Nicolò Peruzzi — Portfolio

My web designer & developer portfolio, live at [npdevelopment.xyz](https://npdevelopment.xyz): case studies, services and process. Localized in five languages (IT, EN, DE, ES, PT) with `next-intl`, dark/light theme, generated sitemap, hreflang alternates and JSON-LD.

**Stack:** Next.js (App Router) · TypeScript · Tailwind CSS · next-intl

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```
