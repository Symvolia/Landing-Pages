# Hotel Bella Vista

Concept project: a landing site for a four-star seaside hotel. It opens with an immersive walk through the resort (arrival, house, infinity pool, rooms, spa, restaurant, sunset terrace): the scroll moves a camera forward through each area while signs, photos and details float past in CSS 3D. Then rooms, services, gallery and booking contacts.

**Live demo:** https://hotel-bellavista-umber.vercel.app/ · Part of my portfolio at [npdevelopment.xyz](https://npdevelopment.xyz)

**Stack:** React · Vite · Tailwind CSS · GSAP ScrollTrigger + Lenis (scroll-driven 3D journey, smooth scroll) · Swiper (carousels) · AOS (scroll animations) · Lucide icons

With *reduce motion* enabled, the journey becomes a plain list of the areas.

## Run locally

```bash
npm install
npm run dev     # development server
npm run build   # production build in dist/
```
