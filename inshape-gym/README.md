# InShape Gym

Concept project: a landing site for a fitness club: classes, trainers, plans and a contact form. Available in Italian, English, German and Portuguese.

**Live demo:** https://inshape-gym-ruddy.vercel.app/ · Part of my portfolio at [npdevelopment.xyz](https://npdevelopment.xyz)

**Stack:** React · Vite · Tailwind CSS · Framer Motion · EmailJS · Lucide icons

## Run locally

```bash
npm install
npm run dev     # development server
npm run build   # production build in dist/
```
